说明：
本mod将游戏中的繁体中文转换为简体中文，部分菜单、装备和设置说明中的部分用词采用本地化表达，新增了部分繁体中文遗漏的设置描述，参考英文原文本修改了部分错误翻译。

安装：
在 Steam 中把《Battlefield 4™》的游戏语言设为繁体中文。下载并解压压缩包。右键 Install.cmd，选择以管理员身份运行。等待安装完成，再启动游戏即可。

卸载：
退出游戏，右键 Uninstall.cmd，选择以管理员身份运行，等待卸载完成即可恢复原版。
安装时会自动备份原文件，请保留补丁生成的备份，以便卸载时恢复。

检查和修复：
由于部分文字与EA客户端绑定，可能会随着游戏或客户端的更新而被强行恢复为原版或出现启动异常及报错等行为，如果需要检查汉化文件和卸载所需的备份是否完整，请打开Check & Repair文件夹，右键Check.cmd，选择以管理员身份运行，显示 HEALTHY 表示检查通过。如果发现文字已被覆盖需恢复汉化文件时，右键Repair.cmd，选择以管理员身份运行，完成后重新启动游戏即可。
若遇到其他问题，请把窗口中的错误提示截图发到本仓库的 Issues或邮件zac032203@gmail.com联系我。

注意：
基于 Windows 11 Steam 版（Build ID:10351742）开发，其他版本暂未验证，支持情况未知。
